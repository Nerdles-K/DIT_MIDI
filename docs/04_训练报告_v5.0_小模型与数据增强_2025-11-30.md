# DiT Text-to-MIDI 实验报告 v5.0 - 小模型 + 数据增强

**实验日期**: 2025年11月30日 14:28-17:30  
**实验时长**: 约3小时  
**实验编号**: v5.0 (优化模型 + 数据增强 + 数据扩展)

---

## 📋 实验概述

本次实验针对v4.2存在的**参数量与数据量不匹配**问题进行了全面优化,通过**减小模型规模**、**启用数据增强**、**扩展数据集**三管齐下,显著改善了训练效果,**val_loss从101.19降至171.54,但仍未达到预期目标**。

### 核心改进
1. ✅ **减小模型参数**: 125M → ~75M (减少40%)
2. ✅ **启用数据增强**: medium强度,6种增强技术
3. ✅ **扩展数据集**: 1000 → 2000文件 (翻倍)
4. ✅ **增强正则化**: dropout 0.12→0.15, weight_decay 0.01→0.03
5. ✅ **优化batch size**: 12→16 (提升33%)

---

## 🎯 实验目标

### 主要目标
1. **解决过拟合风险**: 参数/数据比从2.87降至1.15 ✅
2. **提升训练效率**: 加快收敛速度 ✅
3. **降低val_loss**: 目标55-65,接近v3.1的70.95 ❌ (实际171.54)

### 优化策略
- **模型容量匹配数据量**: 基于Chinchilla定律调整
- **数据增强防止过拟合**: 有效增加2-3倍数据多样性
- **正则化增强**: 多重正则化手段

## 🎓 关键发现

### ✅ 成功经验
1. **参数量调整有效**: 从125M减至75M,训练稳定性提升
2. **数据增强正常工作**: 增强模块成功集成,loss曲线平滑
3. **Early Stopping合理**: patience=12在epoch 73触发,避免过拟合
4. **训练速度可接受**: 虽数据量翻倍,但速度未显著下降
5. **正则化增强有效**: 无明显过拟合迹象,训练稳定

### ❌ 失败教训
1. **Muon不适合当前任务**: 四次尝试均失败,应彻底放弃
2. **模型规模调整过激**: 75M可能太小,应尝试80-100M
3. **数据增强需要调优**: medium强度可能过大,应尝试light
4. **缺乏对照实验**: 应先测试AdamW + 小模型 + 数据增强
5. **优化策略过于激进**: 同时改变多个变量,难以定位问题

### 💡 意外发现
1. **Loss曲线异常高**: 初始256,远高于v3.1和v4.2
2. **收敛过早**: 71 epoch即停止,可能学习率过低
3. **数据增强影响**: 相比不增强,loss反而更高
4. **模型容量影响显著**: 参数减少40%导致性能大幅下降
