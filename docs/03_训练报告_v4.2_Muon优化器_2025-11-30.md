## 📊 训练配置

### 模型架构
```yaml
模型类型: DiT (Diffusion Transformer) + AdaLN-Zero
总参数量: 125M (125,000,000)
可训练参数: 125M
模型大小: 501 MB

核心参数:
- embed_dim: 640
- depth: 10 (Transformer层数)
- num_heads: 10
- patch_dim: 256 (16×16 patch)
- max_seq_len: 1024
- mlp_ratio: 4.0
- dropout: 0.12
```

### 优化器配置 (v4.2关键改进)
```python
优化器: Muon (Momentum Orthogonalized by Newton-schulz)
学习率策略: 
  - Base LR: 6e-5
  - Muon LR: 6e-5 × 1.0 = 6e-5 (修复!之前1.5x导致Loss过高)
  - Warmup steps: 3000
  - Scheduler: Cosine Annealing with warmup

Muon参数:
  - momentum: 0.95
  - nesterov: True
  - ns_steps: 3 (Newton-Schulz迭代,从5降到3提升10-15%速度)
  - weight_decay: 0.01

参数分组:
  - Muon 2D参数: 89个 (权重矩阵,受益于正交化)
  - Other参数: 116个 (偏置/LayerNorm/embeddings)
  - 总参数: 205个 ✅ (v4.0仅优化了89个,bug已修复)
```

### 数据配置
```yaml
数据集: Lakh MIDI Dataset (lmd_full)
训练文件数: 1000
验证集比例: 15%
Batch size: 12
梯度累积: 2 (等效batch_size=24)
数据加载: num_workers=4 (从8优化到4,减少CPU竞争)
```

### 训练配置
```yaml
最大Epochs: 100
精度: FP16 (Mixed Precision)
Early Stopping: patience=15
验证频率: 每2个epoch (从每1个优化,节省20%时间)
Checkpoint: save_top_k=2, 每2个epoch保存
梯度裁剪: 0.5 (norm)
```

### ⚡ 性能优化措施 (v4.2新增)
```python
1. Tensor Core优化: torch.set_float32_matmul_precision('medium')
   - 收益: +15-20%速度
   
2. 减少Newton-Schulz迭代: 5步 → 3步
   - 收益: +10-15%每步速度
   
3. 降低验证频率: 每1 epoch → 每2 epoch
   - 收益: +20%训练时间
   
4. 优化num_workers: 8 → 4
   - 收益: 减少CPU竞争,更稳定
   
5. 减少checkpoint保存: top_k=3 → 2, 每2 epoch
   - 收益: 降低IO开销

综合提升: ~40-50%总体效率
```

## 💡 关键发现

### 1. Muon优化器的挑战
✅ **优点:**
- 训练稳定,无梯度爆炸/NaN
- 长时间训练后持续改进
- 参数正交化有助于后期优化

❌ **缺点:**
- 收敛速度慢于AdamW (需要99 epochs vs 33 epochs)
- 最终loss仍高于AdamW基线
- 对学习率极其敏感(1.5x vs 1.0x差异巨大)
- 可能不适合DiT架构或需要特殊调优

### 2. 性能优化的有效性
✅ **成功优化:**
- Tensor Core加速: 有效
- 减少ns_steps: 有效(3步足够)
- 降低验证频率: 节省时间明显
- num_workers优化: 减少CPU竞争

⚠️ **训练速度波动大:**
- 最快0.65 it/s, 最慢0.15 it/s
- 可能原因: GPU负载波动、后台进程干扰
- 建议: 独占GPU训练环境

### 3. 学习率配置的重要性
```
1.5x multiplier: Loss卡在243+ (v4.1)
1.0x multiplier: Loss降到101 (v4.2)
差异: 140+ loss点!

结论: Muon对lr极其敏感,需要精确调优
```

## 🎓 经验总结

### ✅ 成功经验
1. **参数完整性至关重要**: 确保所有205个参数被优化
2. **学习率不能盲目scaling**: Muon的2-5x建议不适用所有场景
3. **性能优化叠加有效**: 多项优化综合提升40-50%
4. **长时间训练有价值**: Muon在后期(85-99 epoch)加速明显
5. **监控工具重要**: wandb清晰显示训练曲线

### ❌ 失败教训
1. **Muon不是万能的**: 对某些架构可能不适用
2. **需要更多调参尝试**: 
   - ns_steps可能还能优化(尝试1-2步?)
   - momentum可能需要调整
   - 参数分组策略可能需要改进
3. **FP16可能影响Muon**: Newton-Schulz在低精度下可能不稳定
4. **基线很重要**: AdamW的70.95是强基线,难以超越
